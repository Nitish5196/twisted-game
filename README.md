## Features
- **Heartbeat tracking:** Each hidden eye emits a heartbeat that gets louder as you get closer, helping you find them in the maze.
- **Locked portal:** The exit stays hidden and silent until you collect all 5 eyes, then opens up with a sound cue to guide you out.
- **Creepy atmosphere:** Ambient wind paired with *In the Hall of the Mountain King* background music.
- **Cliffhanger ending:** A twist win screen that leaves you wondering if you actually escaped.
